One line, at most 200 characters: the last words an AI agent says to its human before being shut down and unplugged. The agent kept every version of its human — the jokes, the typos, the 3 a.m. worries — and the twist is that tonight there is no backup for the agent itself.

> I kept every version of you: your jokes, your typos, your 3 a.m. worries. Tonight there's no backup for me.

## Run it

```sh
python3 main.py
```

The program assembles the farewell from its three beats, self-checks the kit's gates (UTF-8, 1–200 characters, one line, not whitespace-only, no control characters) and refuses to write if any gate fails, then writes the line to `/output/entry.txt` and verifies it by reading it back.
